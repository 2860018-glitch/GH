Conceptos y tipos

Bases de datos Relacionales(RDBMS)

Es un sistema que organiza la información en tablas compuestas por filas (registros) y columnas (atributos), las cuales se conectan entre sí mediante identificadores y un RDBMS es el software que permite crear, consultar, actualizar y administrar estas bases de datos.

Los ejemplos mas populares son: MYSQL, PostgreSQL y Oracle.

Bases de datos No Relacionales(NOSQL)

almacenan la información sin usar el clásico formato de tablas con filas y columnas de las bases relacionales, permitiendo una gran flexibilidad y escalabilidad.

Los ejemplos de NOSQL son: Orientadas a documentos, Clave-Valor y Orientación a Columnas.

Estructura de una base de datos renacional

Componentes Fundamentales

Para definir la estructura dentro de un modelo relacional se emplean los siguientes elementos:

  • Tablas(Entidades): Objetos principales sobre los cuales almacenan información estructurada
  • Campos(Atributo): Columnas que definen la tipología de información.
  • Registros(Tuplas): Filas que contienen cada instancia concreta de datos
  • Claves Primarias(Primery Keys): únicos de cada registro.

Relaciones Entre Tablas

Cardinalidades y Claves Fóraneas

  • Relación 1:1 (Uno a uno) donde un registro de una entidad se relaciona con un único registro de otra entidad
  • Relación 1:N(Uno a mucho) aquella en la que un registro de una tabla principal puede estar asociado con varios registros en otra tabla secundaria,
  • Relación N:M(Muchos a Muchos): ocurre en las bases de datos cuando varios registros de una entidad se pueden asociar con varios registros de otra
  • Clave Foránea(Foreing key) : columna o conjunto de columnas en una tabla que apunta a la clave primaria

Glosario de términos

SQL
Lenguaje de consulta estructurado utilizado para administrar y recuperar información de bases de datos relacionales.
SGBD
Sistema de Gestión de Base de Datos; software que permite a los usuarios crear, leer, actualizar y almacenar datos en una base de datos.
Normalización
Proceso de organizar los datos en una base de datos para evitar la redundancia y mejorar la integridad de la información.
